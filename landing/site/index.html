ITPEA Databases in IMAS

Multi-machine ITPA databases, migrated from their original CSV tables into the IMAS summary IDS, one SimDB entry per pulse.

Browse the data SimDB API Migration docs

How the data gets here

  1. Source CSV

    The published database table, one row per time slice.

  2. Crosswalk

    A per-database workbook mapping each column to an IMAS path, with unit transforms, no-data markers and duplicate resolution.

  3. IMAS summary IDS

    Each pulse is written as an IMAS summary IDS, following the Data Dictionary paths in the crosswalk.

  4. SimDB

    One entry per pulse, searchable by machine, pulse and metadata.

Access from Python or the command line

Register this server as a SimDB remote once, then list or query entries:

simdb remote config new itpa https://itpea-db.iter.org/scenarios/api \
    --firewall F5 --username <your ITER login>
simdb remote itpa list

The analysis notebooks in the ITPA-IMAS-Migration repository read their data from this server through the same API.
